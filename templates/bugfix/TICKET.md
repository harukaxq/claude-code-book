# クーポンを使うと、送料無料のはずなのに送料が加わる

## 報告内容

ケーブルホルダーを8個カートに入れると送料無料になりますが、クーポン`TENOFF`を適用すると送料500円が加わります。
商品と数量は変えていません。クーポンを使っても送料は変わらないはずなので、原因を調べて修正してください。

## 再現手順

1. TinyCommerceを起動し、ブラウザで`http://localhost:5173`を開きます。
2. カートの商品をケーブルホルダー（1個680円）8個だけにします。
3. クーポン欄を空にして「適用」を押します。商品小計5,440円、割引0円、送料0円、支払合計5,440円であることを確認します。
4. クーポン欄に`TENOFF`を入力して「適用」を押します。

## 実際の結果と期待する結果

`TENOFF`を適用すると、商品小計の10％にあたる544円が割り引かれますが、送料500円が加わります。

| 項目 | 実際の結果 | 期待する結果 |
| --- | ---: | ---: |
| 商品小計 | 5,440円 | 5,440円 |
| クーポン割引 | 544円 | 544円 |
| 送料 | 500円 | 0円 |
| 支払合計 | 5,396円 | 4,896円 |

[仕様書](docs/spec.md)の「6.4 送料と支払合計」では、割引前の商品小計が5,000円以上なら送料無料で、クーポン割引は送料無料の判定に影響しないと定めています。
今回の商品小計は5,440円なので、クーポンを適用しても送料は0円、支払合計は5,440−544＝4,896円になるはずです。

## 修正後に確認したいこと

- 上の再現手順で、割引544円、送料0円、支払合計4,896円になること。
- 同じ商品・数量・クーポンで注文したときも、カートと注文の金額が期待する結果と一致すること。
- クーポンなしの場合や商品小計が5,000円未満の場合も、金額計算が仕様どおりであること。
- 商品が入っていないカートには、引き続き送料がかからないこと。
